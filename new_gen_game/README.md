# new_gen_game — 3D-арт через Blender

Экспериментальная папка: модели строятся скриптами на Python прямо в Blender
(без ручного моделирования), рендерятся ортографической камерой под углом игры
в PNG с прозрачным фоном. Игру (`cmd/`, `internal/`) эта папка не трогает.

```
blender/lib.py        общие хелперы: сцена, свет, камера, процедурные материалы, Builder
blender/<model>.py    одна модель = один скрипт (сейчас: warehouse.py)
renders/              результаты рендера
compare.py            сравнение со старым спрайтом (большой размер + размер в игре)
run.ps1               запуск: .\new_gen_game\run.ps1 warehouse [разрешение] [сэмплы]
```

Blender: `M:\blender-5.2.3-candidate+...\blender.exe` (переопределяется `$env:BLENDER`).
Рендер — Cycles на GPU (OptiX), ~10–20 с на кадр 1024×1024.

Камера: ортографическая, высота 35°, смотрит с юго-востока (+X/−Y) — видны
передний (−Y) и правый (+X) фасады. 1 единица Blender ≈ 1 клетка.
