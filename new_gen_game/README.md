# new_gen_game — 3D-арт через Blender

Экспериментальная папка: модели строятся скриптами на Python прямо в Blender
(без ручного моделирования), рендерятся ортографической камерой под углом игры
в PNG с прозрачным фоном. Игру (`cmd/`, `internal/`) эта папка не трогает.

```
blender/lib.py        сцена, свет, камера, процедурные материалы, Builder, контур, дым
blender/props.py      бочки, ящики, мешки, тележка, забор, двери, трава, плющ, снопы
blender/house.py      генератор фахверкового дома (стены, проёмы, фронтоны, крыша)
blender/<здание>.py   warehouse, mill, bakery, smeltery
blender/serf.py,
blender/units.py      персонажи (делает Codex, см. CODEX_TASK_serf.md)
models/*.blend        редактируемые сцены — открывать в Blender
renders/              результаты рендера
compare.py            сравнение со старым спрайтом (большой размер + размер в игре)
sheet.py              кадры -> спрайт-лист + GIF-превью
```

Запуск (из корня репозитория):

```
blender.exe -b --factory-startup --python new_gen_game/blender/<здание>.py -- new_gen_game/renders/<здание>.png [разрешение] [сэмплы] [кадры]
python new_gen_game/sheet.py new_gen_game/renders/<здание>_frames 10
```

Blender: `M:\blender-5.2.3-candidate+...\blender.exe`. Рендер — Cycles на GPU
(OptiX), ~15–25 с на кадр 1024×1024.

## Соглашения

- Камера: ортографическая, высота 35°, смотрит с юго-востока (+X/−Y) — видны
  передний (−Y) и правый (+X) фасады. 1 единица Blender ≈ 1 клетка.
- Цвета — `Standard` view transform (насыщенные, «рисованные»), не AgX.
- Контур — inverted hull (`Builder.build(outline=...)`), не Freestyle: в этой
  сборке Blender Freestyle на нормальном разрешении линий не рисует.
- Вариации цвета у сотен одинаковых деталей (черепица, камни) — атрибут
  `tint` на примитиве, а не отдельные материалы.

## Анимации

- **Мельница**: крылья на отдельном риге (`sail_spin`), в `.blend` — полный
  оборот за 96 кадров (пробел в Blender). Для игры — 8 поз на четверть
  оборота (`mill_sheet.png`), крылья одинаковые, поэтому цикл бесшовный.
- **Дым** (пекарня, плавильня): объёмные клубы `lib.add_smoke`, цикл 16
  кадров. Рендерится **отдельным слоем** (`*_smoke_frames`, здание как
  holdout — закрывает дым позади себя) той же камерой, что и здание
  (`*_base.png`). В игре: рисовать здание, поверх — текущий кадр дыма.

## Лёгкие модели для Unity (`lowpoly.py`)

Первые четыре здания (склад, мельница, пекарня, плавильня) делались под
спрайты: каждая черепица — отдельная геометрия, плюс фаски — 150–300 тыс.
треугольников. Для 3D-игры, которая должна идти и на встроенной видеокарте,
все новые здания строятся набором `lowpoly.py`:

- стены, крыши, балки — простые коробки/призмы, без фасок;
- черепица, брёвна, доски, камень — узором в материале (запекается в
  текстуру), а не геометрией;
- отделаны все четыре стороны (камеру в Unity можно вращать);
- бюджет — 1–3 тыс. треугольников на здание.

Скрипты: `tavern.py`, `farm.py`, `lumberjack_hut.py`, `carpentry.py`,
`quarry_hut.py`, `miner_hut.py`, `fisher_hut.py`, `pig_farm.py`,
`meat_workshop.py`, `winery.py`. Запуск печатает число треугольников:

```
blender.exe -b --factory-startup --python new_gen_game/blender/tavern.py -- new_gen_game/renders/tavern.png 768 48
```

Экспорт в Unity — всегда с `--game`: фаски/трава/плющ убираются, все детали
склеиваются в одну сетку с одной текстурой (один вызов отрисовки на здание),
свечение окон печётся отдельной маской (`*_emit.png`):

```
blender.exe -b new_gen_game/models/tavern.blend --python new_gen_game/blender/export_unity.py -- M:/strategy_game_unity/Assets/Models/tavern.fbx 1024 --game
```
