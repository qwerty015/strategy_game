# Задачи для Codex: персонажи (юниты)

Контекст: папка `new_gen_game/` — эксперимент по переходу на 3D-арт через
Blender. Модели строятся **скриптами на Python** и рендерятся без окна.
Посмотри `README.md`, `blender/lib.py`, `blender/props.py`, `blender/house.py`
и здания (`warehouse.py`, `mill.py`, `bakery.py`) — там камера, свет,
материалы, `Builder` и **контур** (`Builder.build(outline=...)`).

Blender: `M:\blender-5.2.3-candidate+v52.32ede9dba158-windows.amd64-release\blender.exe`
Запуск: `blender.exe -b --factory-startup --python new_gen_game/blender/serf.py -- <out.png> [res] [samples]`

## Правила (не меняются)

- **Не редактируй** `lib.py`, `props.py`, `house.py` и скрипты зданий — над
  ними параллельно работает Claude. Свои хелперы — в `blender/units.py`.
  Нужно что-то в `lib.py` — напиши, Claude добавит.
- Не трогай игру (`cmd/`, `internal/`).
- **Коммить свою работу сам**, только свои файлы (`serf.py`, `units.py`,
  `<unit>.py`, `models/<unit>.blend`, `renders/<unit>_*.png`). Сейчас
  `serf.py`, `units.py`, `models/serf.blend`, `renders/serf_*.png` лежат
  незакоммиченными — закоммить их первым делом. `*.glb` в git не кладём.
- Проверяй результат, открывая PNG (лучше на зелёном фоне, как трава), а не
  только по отсутствию ошибок в логе.

## Этап 2: доработка слуги (по ревью)

1. **Ходьба живее.** Сейчас шаг и мах рук почти незаметны, на 64 px
   персонаж «плывёт». Нужно: шаг бедром ±30–35°, колено сгибается в фазе
   переноса (~40–50°), руки в противофазе ±25–30°, вертикальное
   покачивание таза (вниз в фазе опоры, вверх в фазе переноса, ~0.03–0.04),
   лёгкий наклон корпуса вперёд. Проверка: на кадре 64×64 видно, какая нога
   впереди.
2. **Контур как у зданий.** Используй `Builder.build(..., outline=0.008)` —
   тонкий тёмный inverted-hull контур (см. `lib.outline_material`). Без него
   юниты не впишутся в стиль зданий. Толщину подбери, чтобы на 64 px линия
   была ~1 px.
3. **Меньше «деревянного манекена».** Шары-суставы на плечах и запястьях
   видны — спрячь их: рукава перекрывают плечо, кисть — простой куб/капля
   телесного цвета, без шара на запястье. Шапку чуть меньше (сейчас почти с
   голову). Добавь пояс с мешочком и закатанные рукава — мелкие детали,
   которые читаются.
4. **Персонаж крупнее в кадре.** Сейчас силуэт занимает ~40 % ячейки 256 px.
   Сделай ~70–75 % высоты (тот же фиксированный `ortho_scale` для всех
   кадров/направлений — это правильно, оставь).
5. Отдельно отдай `renders/serf_walk_preview.gif` — одно направление,
   цикл ходьбы (можно через `python new_gen_game/sheet.py <папка_кадров> 10`).

## Этап 3: остальные профессии (после этапа 2)

Тот же скелет и анимации, меняется одежда, инструмент и рабочая анимация:

| Юнит | Одежда/цвет | Инструмент | Рабочая анимация (`work`, 6–8 кадров) |
|---|---|---|---|
| лесоруб | зелёная куртка, капюшон | топор | рубка (замах сверху) |
| каменотёс | серый фартук | кирка | удар киркой |
| рудокоп | тёмная одежда, каска с фонарём | кирка | удар киркой |
| рыбак | синий, широкополая шляпа | удочка | заброс |
| фермер | соломенная шляпа | серп/коса | жатва |
| строитель | кожаный фартук | молоток | забивание |

Плюс общая для всех анимация `death` (4 кадра — оседает и падает). Сделай
сначала **лесоруба** целиком (walk/idle/carry с бревном/work/death), потом
остальных по образцу. Общий код персонажа — в `units.py`, профессия — в
своём `<unit>.py`.
