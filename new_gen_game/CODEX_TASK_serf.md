# Задача для Codex: 3D-модель слуги (serf) с анимацией ходьбы

Контекст: папка `new_gen_game/` — эксперимент по переходу на 3D-арт через
Blender. Модели строятся **скриптами на Python** и рендерятся без окна.
Посмотри `README.md`, `blender/lib.py`, `blender/props.py` и
`blender/warehouse.py` — там готовые камера, свет, материалы, контур и
`Builder` (сборка примитивов в меши). Пример результата —
`renders/warehouse.png`, модель — `models/warehouse.blend`.

Blender: `M:\blender-5.2.3-candidate+v52.32ede9dba158-windows.amd64-release\blender.exe`
Запуск: `blender.exe -b --factory-startup --python new_gen_game/blender/serf.py -- <out.png> [res] [samples]`

## Что сделать

1. `blender/serf.py` — низкополигональный стилизованный человечек-слуга
   (простая рубаха, штаны, сапоги, шапка; пропорции «чиби» ~1:3–1:4,
   рост ~0.9 единицы Blender = чуть меньше клетки). Тёплая палитра как у склада.
2. **Скелет (Armature)**: таз, позвоночник, голова, руки (плечо/предплечье),
   ноги (бедро/голень/стопа). Меш привязан к костям (veрtex groups /
   Automatic Weights или жёсткая привязка частей к костям — для low-poly
   жёсткая привязка нормальна).
3. **Анимация ходьбы**: цикл 8 кадров (Action `walk`), плюс `idle` (2–4 кадра,
   лёгкое дыхание). Второй вариант ходьбы с ношей (мешок на плече) — `carry`.
4. **Рендер спрайт-листа**: 8 направлений (0°, 45° … 315°, поворот модели,
   камера та же — `lib.add_game_camera()`), каждый кадр 256×256, прозрачный
   фон. Лист: строки = направления, столбцы = кадры →
   `renders/serf_walk.png`, `renders/serf_idle.png`, `renders/serf_carry.png`.
   Важно: масштаб камеры (`ortho_scale`) **одинаковый** на всех кадрах и
   направлениях (не `frame_camera` на каждый кадр), иначе персонаж будет
   «дышать» размером.
5. Сохранить `models/serf.blend` (`lib.save_outputs`) — со скелетом и
   действиями, чтобы его можно было открыть в Blender и покрутить.

## Правила, чтобы не конфликтовать с Claude

- **Не редактируй** `blender/lib.py`, `blender/props.py`, `blender/warehouse.py`
  — над ними параллельно работает Claude. Нужны свои хелперы — клади их в
  новый `blender/units.py`. Если в `lib.py` чего-то реально не хватает —
  напиши об этом, а не правь.
- Не трогай игру (`cmd/`, `internal/`) — это пока только арт-эксперимент.
- Коммиты — только своих файлов (`serf.py`, `units.py`, `models/serf.blend`,
  `renders/serf_*.png`). `*.glb` в git не кладём (уже в `.gitignore`).
- Проверяй результат, открывая отрендеренные PNG, а не только по отсутствию
  ошибок в логе.
