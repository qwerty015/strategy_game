# Модули каменной стены

Все PNG имеют размер 64×64 и загружаются игрой при старте. Направления указаны относительно клетки стены: север — вверх экрана, восток — вправо.

| Файл | Назначение |
| --- | --- |
| horizontal.png | Прямая стена с соседями слева и справа. |
| vertical.png | Прямая стена с соседями сверху и снизу. |
| corner_ne.png | Угол: продолжение **вверх** и **вправо**. |
| corner_nw.png | Угол: продолжение **вверх** и **влево**. |
| corner_se.png | Угол: продолжение **вправо** и **вниз**. |
| corner_sw.png | Угол: продолжение **вниз** и **влево**. |
| pillar.png | Одиночная клетка стены без соседей. |

Т-образные соединения и перекрёстки намеренно не поддерживаются: игра не даёт создать такую топологию стены.

## Ворота

Ворота лежат уровнем выше, в ../gate/:

| Файл | Назначение |
| --- | --- |
| horizontal_closed.png / horizontal_open.png | Ворота в горизонтальном участке стены. |
| vertical_closed.png / vertical_open.png | Ворота в вертикальном участке стены. |

## Правка в Photoshop

Можно редактировать четыре corner_*.png напрямую: прозрачность фона обязательна, размер не менять (64×64). После правки перезапустите игру — ассеты внешние и считываются при запуске.

tools/generate_wall_sprites.go генерирует весь набор из исходного листа и перезапишет ручные изменения. Не запускайте его после Photoshop-правки, пока не сохраните свою версию углов в другом месте.
