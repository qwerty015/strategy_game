# Настройки игры

Файл **settings.json** находится рядом с EXE. При запуске
`go run .\cmd\game\` из проекта — в корне проекта.
Настройки отдельны от сохранений партий: загрузка мира их не меняет.

```json
{
  "language": "ru",
  "music_volume": 0.25,
  "sfx_volume": 0.55
}
```

- Язык: `ru` или `en`.
- Громкость музыки и эффектов: от `0` (выключено) до `1` (100%).
- Без файла используются значения выше. При старте файл не создаётся.
- При изменении языка или любой громкости в меню файл записывается автоматически.
- Неподдерживаемые значения заменяются стандартными; повреждённый JSON
  не мешает запуску (стандартные настройки, ошибка в журнале).
- Запись атомарная; при ошибке доступа игра продолжает работать и сообщает об ошибке.
- Сборщик сохраняет существующий `bin/settings.json` при пересборке.

Не путать: `settings.json` в корне — настройки запуска из исходников,
`bin/settings.json` — отдельные настройки собранной игры.
